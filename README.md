## Project Overview

This project was created for Assignment 5. It demonstrates JavaScript fundamentals, including variables, functions, arrays, loops, conditions, DOM manipulation, event handling, and form validation.

## Tasks

### Task 1: Code Breaker

A browser game in which the player tries to guess a secret four-digit code within eight attempts. The game provides feedback to help the player identify correct digits and correct positions.

**Technologies:** HTML, CSS, JavaScript

### Task 2: Kanban Board

A task management board with three columns. It displays tasks, organizes them by priority, supports tag filtering, and shows task progress.

**Technologies:** HTML, CSS, JavaScript, DOM manipulation

### Task 3: Character Creator

An interactive form that allows users to create a character by entering a name, choosing a class and color, and distributing skill points. The form validates user input and displays a character preview.

**Technologies:** HTML, CSS, JavaScript, form validation

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a web browser.
4. Select a task from the main page to explore its functionality.
